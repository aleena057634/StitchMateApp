StitchMateApp

A mobile application developed to help tailors manage customers, measurements, orders, and payments in one place.
 Features
* User Sign Up and Sign In
* Customer Management
* Customer Measurements
* Measurement Editing and Deletion
* Order Management
* Order Status and Priority
* Payment Management
* Dashboard
* Dark and Light Theme
* Profile Image
* SQLite Local Database

Technologies

* React Native
* Expo
* TypeScript
* Expo Router
* Expo SQLite
* AsyncStorage
